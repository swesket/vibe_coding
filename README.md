# DIGGING — Fashion Site Curation

**Live site → https://vibe-coding-6ou.pages.dev/**

DIGGING은 전 세계 패션 쇼핑 사이트를 직접 검증하고 큐레이션하는 플랫폼입니다. 국내 편집숍부터 해외 럭셔리·리셀 마켓까지, 에디터가 실제로 주문·반품까지 테스트한 사이트만 소개합니다.

## 주요 페이지

- [홈](https://vibe-coding-6ou.pages.dev/)
- [사이트 디렉토리](https://vibe-coding-6ou.pages.dev/sites.html) — 29개 패션 쇼핑 사이트를 카테고리별로 탐색
- [쇼핑 가이드](https://vibe-coding-6ou.pages.dev/guide.html)
- [브랜드](https://vibe-coding-6ou.pages.dev/brands.html)
- [블로그](https://vibe-coding-6ou.pages.dev/blog.html)
- [소개](https://vibe-coding-6ou.pages.dev/about.html)

각 사이트별 상세 리뷰 페이지(가격대·한국 배송/관세·장단점·에디터 총평)를 4개 언어(한국어·영어·중국어·일본어)로 제공합니다.

## 기술 스택

바닐라 HTML/CSS/JS로 만든 정적 멀티페이지 사이트. 빌드 도구 없이 Cloudflare Pages에 배포됩니다.

- 다크/라이트 테마, 색각 보조 모드(적록 색약·완전 색맹), 4개 언어 i18n
- 접근성(WCAG AA), 반응형(768px 브레이크포인트)
